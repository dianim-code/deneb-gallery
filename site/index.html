Deneb for Power BI

Deneb template gallery

Six reusable Vega-Lite templates, each rendered here on the same gold dataset: ordinary hospital beds per 1,000 residents, Italy 2021 to 2023. Copy a template and import it into a Deneb visual, or open its README for the field list.

Versions pinned to those bundled by Deneb 2.0.1: Vega 6.4.0, Vega-Lite 6.4.3, vega-embed 7.1.0. Source: github.com/dianim-code/deneb-gallery.

Use a template in Power BI

  1. Click Copy template on a card. The template JSON is copied to the clipboard.
  2. In Power BI Desktop, add a Deneb visual, then add at least one column or measure so the advanced editor opens.
  3. Open the advanced editor, choose Create New Specification, select Existing template, and paste the JSON (Ctrl+V).
  4. Map each placeholder to a column or measure from the list, then click Create. Each card's README gives the field list and types.

Import steps follow the Deneb templates documentation.
